A two-line warning to my past self about one specific moment — and one
sentence on why it mattered. Entry for the
[make.fun bounty](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca)
($2, winner-takes-all, free to enter).

## The entry

> Don't laugh when Maya trips in the hallway on the first day of seventh grade.
> She never forgot that laugh, and after that day she stopped sitting with you at lunch.

164 characters (including the newline between the lines), inside the 1–280
character gate.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

Python 3 stdlib only, no network, deterministic — the same bytes on every run.
